E-Commerce Website for Electronics (Laptops, Mobiles, AirPods & Accessories)

This is a fully functional e-commerce website built to simulate a real-world online store specializing in electronics such as laptops, mobile phones, AirPods, and related accessories. It is developed using a combination of HTML, CSS, JavaScript, and Django, with SQLite as the backend database for handling product data, user authentication, and order processing.

Features:

Product Catalog: Displays a variety of electronic products like laptops, smartphones, AirPods, and accessories with detailed information.

User Authentication: Users can register, log in, and manage their accounts.

Shopping Cart: Allows users to add, remove, and update items in their shopping cart.

Product Search and Filters: Users can search for specific products or filter by category, price, etc.

Order Management: Users can place orders and view order history.

Admin Dashboard: Admins can add, update, or delete products from the catalog.

Responsive Design: The website is fully responsive and optimized for both desktop and mobile devices.

Backend: Powered by Django, with SQLite as the database for managing product data, user profiles, and order information.

Tech Stack:

Frontend: HTML, CSS, JavaScript

Backend: Django (Python framework)

Database: SQLite

Features: User authentication, session management, shopping cart functionality, admin panel

How to Run:

Clone the repository: git clone <repo-url>

Install dependencies:

pip install -r requirements.txt


Set up the database:

python manage.py migrate


Run the development server:

python manage.py runserver


Open the website in your browser at http://127.0.0.1:8000/.
